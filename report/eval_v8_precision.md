# v0.0.6 混合精度量化：精度 -80%（精度提升专项）

> 目标：把量化路径的精度提上去。基线精度（ETTh1 7×1024，horizon=24，vs 官方 PyTorch）：
> f32 7.6e-6（浮点噪声级）、f16 **0.00370**、bf16 **0.0416** ——差距全部来自权重舍入。

---

## 1. 方法：混合精度量化（dtype 感知加载落地后可行）

- `quantize` 新增 `--keep-f32 <prefix列表>` / `--preset balanced`：指定前缀的 2D 权重保留 FP32，其余量化。
- 加载器信任检查点**声明的精度**（`config.rs` 新增 `precision_declared`），不做强制整模型再量化
  （否则保留的 f32 张量会被 `model.quantize` 反向转回 half）。逐张量 dtype 直载（v0.0.5 的成果）天然支持混合。
- 排查过程中用调试探针确认：加载、前向均逐张量区分 dtype；**早期"所有变体输出逐位相同"是
  陈旧 export_forecast 二进制（未含 precision_declared 守卫）强制整模型 re-quantize 所致，重建后结果正常。**

## 2. 敏感层扫描（f16，max|Δ| vs 官方）

| keep-f32 组合 | med max\|Δ\| | 全分位网格 | 体积 |
| --- | --- | --- | --- |
| 无（全量 f16 基线） | 0.003702 | 0.006058 | 631 MB |
| +输出头 | 0.003104 | 0.005163 | 633 MB |
| +残差块 | 0.002247 | 0.004572 | 668 MB |
| +尾部层 18,19 | **0.001181** | **0.002214** | 733 MB |
| +尾部层 16..19 | 0.000913 | 0.001849 | 799 MB |
| **+尾部层 17,18,19（balanced）** | **0.000764** | **0.001380** | **766 MB** |
| 头部层 0,1 + 尾部 18,19 | 0.002054 | 0.004699 | 793 MB |

**结论（敏感度排序）**：尾部层 19/18/17 ≫ 残差块 > 输出头 ≫ 头部层。误差随层数累积，
越接近输出越关键；头部层保留几乎无用（误差被后续 19 层淹没）。

## 3. 最终推荐与结果（`--preset balanced`：head + 残差块 + 层 17,18,19 保留 FP32）

| 精度 | med max\|Δ\| | 全分位网格 | corr | 体积 | 误差降幅 |
| --- | --- | --- | --- | --- | --- |
| f32（参照） | 7.6e-6 | 1.0e-5 | 1.0000000 | 1262 MB | - |
| **f16 混合** | **0.000764** | **0.001380** | 1.0000000 | **766 MB** | **-79% / -77%** |
| **bf16 混合** | **0.00830** | **0.00988** | ~1.0000000 | **766 MB** | **-80% / -84%** |

- 分位数单调性（q10≤…≤q90）全部保持 ✓；56 单测通过，fmt/clippy 干净。
- **速度零代价**：纯 f16 与混合版同会话 A/B，forecast 持平（混合版多 ~150ms 装配，来自 5 个 f32 权重转置）。
- RSS 影响可忽略（仅 5 个张量改 f32，~33 MB）。

## 4. 使用

```bash
cargo run --release --bin quantize -- ckpt ckpt_f16_highacc f16 --preset balanced   # 或 bf16
```

## 5. 还可继续的方向

1. **逐层扫描更多组合**：观察曲线尚未饱和（+层16后继续下降），`--keep-f32` 可自由扩展到
   16..19 / 15..19（体积 ~800–830 MB，f16 med 可到 ~8e-4 以下）。
2. **量化误差补偿**：在保留层确定后，对 f16 层的 bias 做一阶偏差校正（需要一层校准激活均值），
   可再压一部分系统性偏差——但对 max\|Δ\| 帮助有限（max 由离群点决定）。
3. 官方对比多数据集（ETTh2/ETTm1/ETTm2 + 压力集）复核 `balanced` 预设的普适性。

复现：`quantize --preset balanced` → `export_forecast <ckpt> 24 data/etth1_ctx.csv <out>` →
`python3 tools/eval_precision.py`。
